Wi-Fi включается и выключается только на экране: «Система → Wi-Fi» (по умолчанию выключен). Сеть не задана — работает только точка доступа (по умолчанию CO2-Hub, пароль co2sensor; текущие — на экране в «Система → Сеть Wi-Fi»), адрес 192.168.4.1. Нет связи с роутером дольше заданного времени — точка доступа включается дополнительно и выключается, как только связь восстановится.

Пароль спрашивается на страницах настроек и при изменении настроек (имя пользователя — любое). Управление с главной страницы (поправка скорости, ночь, коррекция вентилятора) — без пароля. Забыли пароль — на экране «Система → Сброс пароля веба» (станет co2sensor).

Обновление прошивки

Файл — firmware__<версия>.bin для этой платы (, датчик ), папка Build//. Файл от другой платы или датчика — предупреждение перед записью. Образ проверяется перед переключением; новая прошивка, которая не запустилась, откатывается на прежнюю.
