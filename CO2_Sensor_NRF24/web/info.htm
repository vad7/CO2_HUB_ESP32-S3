Стек мин. - наименьший свободный стек задачи с её создания (меньше б - красным). Время и «Итого» - с запуска, доля от времени обоих ядер. Задачи - по ядрам, к которым привязаны; загрузка ядра - за последние 2 с, «итог задач» - сумма «Итого» задач группы. Обновление раз в 2 с.

Задач больше, чем вмещает таблица прошивки (SYSINFO_TASKS_MAX) - список пуст.
